🔧 Changes Applied
uart_fb/rtl/uart_rx.sv
Added clr_errors W1C input port. Error flags made sticky (once set, remain high until explicitly cleared). Removed rxd_prev dead code.
uart_fb/rtl/uart_top.sv
Propagated clr_errors port from uart_rx through top-level wrapper.
uart_fb/rtl/uart_top_verilator.sv
Added LOOPBACK parameter (default=1). Changed hardwired if(1) to if(LOOPBACK). Propagated clr_errors.
uart_fb/tb/tb_uart.sv
Added pass/fail gate with $fatal on failure. Fixed rx_ready handshake bug that caused 969 false failures. Added clr_errors signal.
uart_fb/tb/uart_fcov.sv
Created functional coverage monitor (Iverilog-compatible counter-based tracking). Integrated into tb_uart.sv + Makefile.
uart_fb/tb/tb_uart_parity.sv
Fixed rx_valid timing issue (rx_valid fires during stop bit, before while-loop starts). Added rx_ready handshake + clear_errors() task for W1C sticky flags.
uart_fb/verilator/testbench.cpp
Added clr_errors = 0 initialization in sim_init() to prevent X-propagation in Verilator builds.
uart_fb/rtl/*.sv (5 files)
Added width casts (5'(), 32'(), 4'(), 12'()) to fix all 8 WIDTH lint warnings.
uart_fb/rtl/*.sv (5 files)
Added /* verilator lint_off/on IMPORTSTAR */ pragmas to suppress 5 namespace-pollution warnings.
uart_fb/rtl/uart_rx.sv
Added break_detect output with W1C sticky behavior. Break timer counts x16 ticks while RXD low; threshold at 200 ticks (~12.5 bit periods). Integrates with existing error flag infrastructure (clr_errors).
uart_fb/tb/tb_uart_break.sv
New break detection testbench with 10 tests covering: below/above threshold, W1C clear, consecutive breaks, edge cases with 5-bit config, and post-break normal frame reception.
uart_fb/tb/uart_fcov.sv
Added break_cnt edge-triggered counter for break events.
uart_fb/rtl/uart_top.sv
Added irq output port and int_en_rx/int_en_tx/int_en_err input ports. Combinatorial assign irq = (int_en_rx && rx_valid) || (int_en_tx && tx_ready) || (int_en_err && (framing_error||parity_error||overrun_error||break_detect)).
uart_fb/rtl/uart_top_verilator.sv
Propagated irq and int_en_* ports through Verilator wrapper.
uart_fb/tb/tb_uart_intr.sv
New interrupt testbench with 9 tests covering: RX IRQ enable/disable, TX ready IRQ, parity/framing/overrun error IRQ via injection, IRQ de-assertion after ack, all enables combined, and toggle enables mid-operation.
uart_fb/tb/uart_fcov.sv
Added irq + int_en_* inputs, irq_cnt counter, int_en_cfg_cnt tracking.
uart_fb/tb/uart_fcov.sv
Added per-combination cross coverage: cfg_cross_dps[36] flat-encoded array tracking all data×parity×stop combos. Displays coverage % and lists missing combos in print_summary().
uart_fb/tb/uart_fcov.sv
Added second cross dimension: cfg_cross_baud_data[36] tracking baud×data combinations. Uses baud_idx() function to map divisor to index. Displays coverage with missing combo filtering.
uart_fb/tb/uart_fcov.sv
Added third and fourth cross dimensions: cfg_cross_baud_parity[27] (baud×parity) and cfg_cross_baud_stop[27] (baud×stop). Each 9×3=27 bins using baud_idx*3 + n encoding. All four cross arrays displayed in print_summary().
